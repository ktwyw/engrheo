# Course notebooks

Eighteen executed notebooks built around engineering problems from polymers, food, drilling fluids, cosmetics
and construction materials. Every notebook states its learning objectives, prerequisites and study time,
explains a key algorithm in plain Python ("Inside the algorithm", checked against the library), and ends with
exercises including an "Implement it yourself" task. Worked solutions are in [`../solutions`](../solutions).

## Running the notebooks

- **Google Colab:** open any notebook from GitHub in Colab (e.g.
  `https://colab.research.google.com/github/ktwyw/engrheo/blob/main/notebooks/03_shear_thinning_fluids.ipynb`);
  the first cell installs `engrheo` automatically.
- **Locally:** `pip install -e ".[notebooks]"`, then `jupyter lab`.

The notebooks are generated from `build_notebooks.py`: edit that file, then run
`python notebooks/build_notebooks.py` (or `... build_notebooks.py 05 07` for selected notebooks) to rebuild and execute them.
The data files are generated by `tools/make_course_data.py`.
