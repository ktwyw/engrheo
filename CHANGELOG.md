# Changelog

## 0.1.0 - 2026-09-27

First public release.

- **Library** (`engrheo`, 14 modules): steady-shear models and log-space fitting; rheometer geometries and
  corrections (incl. Couette simulation and Fann 35 / API formulas); non-Newtonian pipe flow, slit flow,
  mixing power and die swell; time-temperature superposition; linear viscoelasticity (spectra, Boltzmann
  superposition, interconversion, regularised spectrum fitting); oscillatory rheology; nonlinear constitutive
  models (UCM/Oldroyd-B, Giesekus, PTT); LAOS analysis; thixotropy; suspensions; extensional rheology; polymer
  melts; 21 bundled course data files.
- **Course**: 18 executed notebooks with learning objectives, "Inside the algorithm" sections and exercises,
  and 18 notebooks of worked solutions.
- **Validation**: 108 checks against exact solutions, independent numerical integration and scipy.
